# location_operations
Tur Yönetim Uygulaması, tur kayıtlarını ekleme, listeleme, güncelleme, silme ve ID’ye göre getirme işlemlerini sağlayan basit bir masaüstü projedir. Kullanıcılar şehir, ülke, kapasite, fiyat, gün/gece ve rehber bilgilerini girerek kayıtları kolayca yönetebilir; proje CRUD ve veritabanı pratiği için geliştirilmiştir.
📌 Tur Yönetim Uygulaması

Bu proje, tur işlemlerini yönetmek için geliştirilmiş basit bir masaüstü uygulamasıdır. Kullanıcıların tur kayıtlarını kolayca ekleyip, güncelleyip, silebilmesini ve listeleyebilmesini sağlar.

🚀 Özellikler
📋 Tur listeleme
➕ Yeni tur ekleme
🔄 Mevcut turu güncelleme
❌ Tur silme
🔍 ID’ye göre tur getirme
🧾 Kullanılan Alanlar
Lokasyon ID
Şehir
Ülke
Kapasite
Fiyat
Gün / Gece bilgisi
Rehber seçimi
🛠️ Teknolojiler
C# (.NET / Windows Forms)
SQL Server (veya kullandığın veritabanı neyse onu yaz)
ADO.NET / Entity Framework (hangisini kullandıysan)
🎯 Amaç

Bu proje, CRUD (Create, Read, Update, Delete) işlemlerini öğrenmek ve API / veritabanı bağlantısı pratiği yapmak amacıyla geliştirilmiştir.
